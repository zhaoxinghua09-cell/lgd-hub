# PRODUCT_PACKAGING_AUDIT（产品包装与可销售性审计 · 2026-11-21）

> 结论：**六个候选里只有一个同时满足"客户看得懂 + 我们交付得出 + 现在就能做"——`MCP Trust Audit`。其余五个，三个不能交付、两个不该卖。**

## 一、六个候选 × 十一项包装要件

要件：名称 / 目标客户 / 客户问题 / 交付内容 / 使用方式 / 交付周期 / 结果样例 / 能力边界 / 定价逻辑 / 售后责任 / 可重复程度

| 候选 | 客户问题 | 交付内容 | 周期 | 能力边界（诚实） | 可重复 | 判定 |
|---|---|---|---|---|---|---|
| **1. MCP Trust Audit（权限 + 证据）** | "我这个 MCP 服务器能不能给 Agent 用？" | 端点/工具清单、权限声明比对、敏感路径与凭证访问、证据包（含 SHA）、一页结论 | 1–2 天 | **只做静态与配置层**；不做运行时利用验证；`gov_scan` 当前只覆盖敏感串 | **高** | **✅ 首选** |
| 2. Pre-deployment Security Assessment（通用 Agent） | "上线前安不安全？" | 规则扫描 + 证据 | 1–3 天 | **当前会把凭证外发判 100/A+**（G2） | 中 | ❌ 先修 P0 |
| 3. Trust Evaluation API | "给我一个 API 打分" | JSON 结果 | 即时 | 分数为 EXPERIMENTAL；无有效期/撤销 | 高 | ❌ 卖 API 会放大误判 |
| 4. Evidence Package | "帮我出一份可复核的证明" | 收据 + kit + 复现说明 | 0.5–1 天 | 只证来源与完整性，**不证安全性** | 高 | ✅ 作为 1 的捆绑件 |

## 二、推荐的唯一最小产品：`MCP Trust Audit`

**一句话定义（客户能懂）**
> 我们对你的 MCP 服务器做一次只读审计：它暴露了哪些工具、要哪些权限、会不会碰密钥和敏感路径；给你一份带哈希的证据包，和一页"能验什么 / 不能验什么"的结论。

**为什么是它（三条，全部有据）**
1. **市场证据最强**：91.8% 缺 OAuth、687 个工具暴露 shell、68 个可报告漏洞、106 个 0-day（公开研究）。
2. **我们现在就能交付**：`gov_scan` 实测命中手机号/邮箱/本地路径（3 high + 1 medium）。
3. **不依赖我们最弱的能力**：不需要"安全评分"（那个还是 EXPERIMENTAL），只需要"事实清单 + 证据"。

**交付样例结构（一页）**
```
1. Scope（被测对象、版本、时间、只读声明）
2. Tools & Permissions（工具清单 / 声明权限 / 实际读取的敏感面）
3. Findings（每条：证据、影响、修复建议、复验方法）
4. Evidence（包 SHA、锚定状态、如何离线复核）
5. What we did NOT test（运行时利用、业务逻辑、提示注入效果）
6. Decision suggestion（是否建议上线 / 需人工复核 / 限制项）——标注"建议，非认证"
```

**定价逻辑**：按次（1–2 天人工）→ 见 `PRICING_AND_UNIT_ECONOMICS.md`，**不给市场成交价**。
**售后责任**：仅对"报告所述事实"负责；不对客户系统安全负责；发现误判免费重做一次。
**可重复程度**：高（对象变化即重做，模板固定）。

## 三、必须写进产品页的"能/不能"

| 能 | 不能 |
|---|---|
| 列出工具、权限声明与敏感访问面 | 证明服务器"安全" |
| 给出可离线复核的证据包 | 发现所有运行时利用（不做动态利用） |
| 指出缺失的认证/授权配置 | 替代客户的风险决策 |
| 提供修复建议与复验命令 | 提供 SLA 或认证 |

## 四、两个不该现在卖的（明确）

- **Trust Evaluation API**：卖 API 等于把 EXPERIMENTAL 分数批发出去，一次误判就是信誉事故；
- **Governance Readiness**：我们自己的授权/监控/撤销都是 0，卖"治理成熟度"是自欺。

## 五、包装层要改的三处（低成本）

1. 产品名统一（不要同时出现 Trust Audit / Xverify / skillgate 三个名字）；
2. 一页 PDF 样张（用公开 MCP 服务器做样例，去掉客户信息）；
3. `--report` 一条命令产出上述六段结构（当前需人工拼装）。
