## 一、外部验证邀请包（P0-3 / P2-10）

### 1.1 谁能算"无关联外部验证者"

满足全部三条才算，缺一条最多算"外部试跑"：

1. 与 XLGD/LGD/MedXpert 无雇佣、无顾问、无股权、无付费关系；
2. 用**自己的机器和网络**执行，不复用我们的任何环境；
3. 回传**原始输出**（不裁剪、不改写），并允许我们在脱敏后公开。

## 二、商业服务包（P2-9）

### 2.1 服务一：Skill 安全评测（按技能包计）

**输入**：技能包目录（含 `SKILL.md` + 脚本）
**交付物**（一次评测 = 一组文件）：

1. `report.json` — 机器可读（schema 见 2.4）
2. `fix-plan.json` — 整改清单：`rule → severity → file:line → 建议动作 → 是否阻断`
3. `report.md` — 人读版（1 页结论 + 证据表）
4. `evidence.json` — 含 `tree_sha256`、`rule_version`、评测时间，可复核

**能力底座（已有，非空谈）**：`skillgate`（规则 + `rule_version` + `--fix-json` + SARIF）；本轮 AST/污点原型在 20 份自建样本上召回 1.00 / 精确 1.00（对标正则基线 0.692 / 0.818）。

**必须如实写的边界**：20 份样本是自建语料，**不是线上漏报率**；对外只能写"在该语料集上"。

### 2.2 服务二：MCP 安全与一致性评测

**输入**：MCP server（stdio 或 HTTP）
**检查项**：

- 协议一致性：`initialize` / `tools/list` / 未知工具 `-32602` / 未知方法 `-32601` / 无 traceback 泄漏
- 工具面：入参边界（如 `a3_assess` 1–5 的越界拒绝）、错误可读性、幂等性
- 授权语义：是否把"评分/通过"误当"允许执行"（对应 P0-2 的三权分离）
- 供应链：包元数据版本与仓库 tag 是否一致

**交付物**：同 2.1 四项 + `protocol_trace.jsonl`（原始 JSON-RPC 往返）

### 2.3 复评与定价草案

| 项 | 说明 |
|---|---|
| 首次评测 | 按包计费（草案：按"技能包 / MCP server"单价，规模档位另议） |
| 整改后复评 | 首次价的 40%–60%（复用证据链，只验差异） |
| 加急 | 建议设上限，避免"付费买快"污染结论 |
| 不承诺项 | **不出售"通过"结论**；不因付费改变阈值；不做"包过" |

### 2.4 机器可读报告 schema（草案）

```json
{
  "schema": "lgd.eval-report/1",
  "subject": {"kind": "skill|mcp", "name": "acme/date-helper", "tree_sha256": "…"},
  "evaluation": {"score": 82, "grade": "A", "dimensions": {"security": 78, "quality": 90}},
  "risk": {"band": "medium", "findings": [
    {"rule": "dynamic-path", "severity": "MEDIUM", "file": "scripts/x.py", "line": 12, "resolved": false}
  ]},
  "rule_version": "lgd-eval/scanner@2026-11-19",
  "evidence": {"manifest_sha256": "…", "evaluated_at": "2026-11-19T…Z", "reproduce_cmd": "…"},
  "authorization": {
    "decision": "NOT_GRANTED",
    "reasons": ["2 unresolved MEDIUM findings under policy P-1"],
    "issuer": "lgd-auth",
    "decision_sha256": "…"
  }
}
```

> 关键点：`evaluation` / `risk` / `authorization` 三段**并列但语义独立**。客户看到分数时，也必须同时看到授权结论，反之亦然。

### 2.5 付费意愿验证（**未执行**）

需要一个不冒犯的问法，且避免"先送免费报告再谈钱"的自我贬值：

1. 先给一份**公开的样例报告**（脱敏的真实样本），让对方看到交付物形态；
2. 再问三个问题：*这个结论你现在用什么替代？* / *一次评测你认为值多少钱？* / *如果只能买一次，你买评测还是买整改？*
3. 记录：愿意付费 / 愿意但价格不符 / 不需要（及原因）。

> 统计口径：**"有兴趣"不算付费意愿**，只有"愿意在 X 价位下单"才算。样本 < 3 时不得对外声称"市场验证"。
