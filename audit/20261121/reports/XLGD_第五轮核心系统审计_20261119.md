## 2. P0 风险清单（按"被外部打中的概率"排序）

**P0-1｜B-01 + E-01：评分直授执行许可**
- 复现：给任意技能打到 ≥96 分 → action 输出 `tier=L0`、日志写"免审批直接执行"。攻击者只需让分数过线，不需要任何授权凭证。
- 影响：跨仓（lgd-gate 被 skill-audit/LGD-Eval 引用）。
- 修复：删除 `tier` 的"权限"语义，改为 `evaluation_tier`（仅表达"证据充分度"）；执行许可另走 `authorization.decide()`，默认 `NOT_GRANTED`。
- 验收：分数 100 且含 CRITICAL 发现 → 必须 `NOT_GRANTED`；分数 100 且证据齐全 → 仍需显式 grant 记录。

**P0-2｜A-08：签名/身份/授权未分离**
- 复现：`grep -r "NOT_GRANTED" uibc_core/` → 0 命中；证书只绑自述身份。
- 影响：所有下游集成方。
- 修复：三权分离 + 默认拒绝（已有可运行原型 `proposals/p02_authorization`，10/10 通过）。
- 验收：`verify=PASS` 且无 grant 时，任何执行入口返回 `NOT_GRANTED`。

**P0-3｜A-09：无来源证据链**
- 复现：全库零 `source_url/fetched_at/parser_version`。
- 影响："证据"只能证明文件存在，无法证明来源，等于无法反驳"你是编的"。
- 修复：见 §3 Source Provenance Chain 设计。

**P0-4｜B-02：评测环境零锁定**
- 复现：`ls LGD-Eval/pyproject.toml requirements*.txt` → 不存在。
- 修复：`uv lock` 或 `pip-compile`，把 lock 文件哈希写进 Evaluation Manifest。

**P0-5｜D-01：Actions 可变引用**
- 复现：`grep -n "uses:" .github/workflows/*.yml` → `@v7`、`@main`、`@release/v1`、`@v0`。
- 修复：全部改 40 位 SHA + 注释版本；对照 uibc-core 已有做法。

**P0-6｜D-04：版本三处不一致**
- 修复路径二选一：(a) 补 `v0.4.0` tag + Release + 对齐 `SPEC_VERSION`；(b) 发 0.4.1 收口。需 Steven 决定。

**P0-7｜E-02：身份验证≠现实身份**
- 修复：证书字段改名 `claimed_subject`，并在报告固定输出 `identity_proof: "self-asserted"`；文档同步。

## 3. 设计件一：Source Provenance Chain（对应 A4/A5/A6）

目标：让"这条法规摘要"能一路回放到"某个官方页面在某一刻的某一段字节"。

```
evidence_item
  └─ source_ref
       ├─ source_id           # sources.json 的 id（cn-nmpa-fgwj）
       ├─ requested_url       # 我们请求的 URL
       ├─ final_url           # 重定向终点（必须记录，否则 302 即失守）
       ├─ http_status
       ├─ fetched_at          # RFC3339 + 时区
       ├─ content_sha256      # 原始响应体哈希（不解压、不转码）
       ├─ content_bytes_len
       ├─ parser               # {name, version, grammar_hash}
       ├─ extract_span         # {start_byte, end_byte} 或 {paragraph_id, char_range}
       └─ extract_sha256       # 摘要文本哈希（可复算）
```

**fail-closed 规则**：
| 情况 | 现有行为 | 应有行为 |
|---|---|---|
| 源不可达 | 无此概念（C-04 只告警） | `source_status=UNREACHABLE`，引用该源的摘要一律 `UNVERIFIED`，检索结果降级并显式警示 |
| 内容哈希变化 | 无法发现（C-03 无哈希） | `source_status=CHANGED`，旧摘要标 `STALE_CONTENT`，需重新复核 |
| 解析失败 | 无此路径 | `source_status=PARSE_FAILED`，禁止产出摘要；不得"跳过继续" |
| 重定向到非同域 | 静默跟随（C-02） | `final_url` 域名不在 allowlist → `source_status=REDIRECTED_OFFSITE`，fail-closed |

**正向测试**：同一 URL 两次抓取、内容不变 → 两个 `content_sha256` 相等，链可复算。
**负向测试**：改 1 字节 → 哈希不等，摘要自动 `STALE_CONTENT`；302 到 `evil.example` → `REDIRECTED_OFFSITE` 且不产出摘要。
**回归测试**：27 枢纽全量重抓，`UNREACHABLE/CHANGED` 数量与人工核对一致。

## 4. 设计件二：Evaluation Manifest（对应 B6）

```json
{
  "manifest_version": "lgd-eval-manifest/1.0",
  "evaluation_id": "<sha256 of this manifest minus id>",
  "subject": {"repo": "...", "commit": "<40-hex>", "artifact_sha256": "..."},
  "engine": {"name": "lgd-gate", "version": "...", "entry_sha256": "..."},
  "rules": {"bundle_sha256": "...", "rule_version": "...", "count": N},
  "environment": {
    "python": "3.13.18", "os": "Windows-11",
    "lockfile": {"path": "uv.lock", "sha256": "..."},
    "dependencies_sha256": "..."
  },
  "tests": {"cmd": "...", "collected": 556, "passed": 531, "failed": 1,
            "skipped": 24, "subtests": 58, "exit_code": 1},
  "artifacts": [{"path": "report.json", "sha256": "..."}],
  "limits": {"known_blind_spots": ["path-deformation", "dynamic-import"]},
  "result": {"score": 61, "verdict": "FAIL", "severity": "CRITICAL"},
  "authorization": {"decision": "NOT_GRANTED", "decided_by": null, "decided_at": null}
}
```

要点：**`result` 与 `authorization` 是两个块**，前者由评测器写，后者只能由人或策略写；缺 authorization 块时任何执行入口按 `NOT_GRANTED` 处理。
