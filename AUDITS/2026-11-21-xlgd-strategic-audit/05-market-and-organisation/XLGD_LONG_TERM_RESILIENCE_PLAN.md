# XLGD_LONG_TERM_RESILIENCE_PLAN（生态韧性与长期可持续性 · 2026-11-21）

> 一句话：**当前生态对"作者本人"的依赖，远大于对"技术"的依赖。** 下面九个崩溃场景逐个推演，能撑住的只有几个。

## 一、九个场景 × 现状

| 场景 | 现状 | 能撑多久 | 缺口 |
|---|---|---|---|
| **作者暂停开发 3 个月** | 代码在 GitHub、有 1015 测试；但无第二维护者 | 3–6 个月（能读能跑），**但无新修复** | 无 BUS_FACTOR / 交接文档 |
| **主要维护者离开** | 同上 | 同上 | 无交接 |
| **GitHub 账号不可用** | 本地有多份克隆（`<local-path>`、`<local-path>`、`<local-path>`）；**无第三方镜像组织** | 短期可恢复 | 无 offsite 镜像、无 org 级托管 |
| **核心域名不可用** | github.io 托管（无自有域名依赖） | 不受影响 | 无自有域名也算一种韧性（意外优点） |
| **外部 API 停止（Rekor）** | 收据可离线校验（`--log-key`），但取新证据需在线 | 校验可继续，**签发中断** | 无备用 log / 本地透明日志 |
| **关键依赖停止维护**（`cryptography` 等） | uibc 依赖少；lgd-engine 依赖少 | 中 | 无依赖清单与替换评估 |
| **资金中断** | 无资金依赖（自费） | 不适用 | 无成本模型（见定价文件） |
| **重要数据丢失** | 本地 D/F 盘 + GitHub；**无异地备份**、无 WeKnora 之外的归档策略 | 中 | 无 3-2-1 备份 |
| **竞争者推出替代** | 已有（VirusTotal、BetterClaw、Microsoft AGT） | — | 差异化未建立（见可防御性） |

## 三、四个 P0 动作（成本极低）

| 动作 | 成本 | 判据 |
|---|---|---|
| **写 `BUS_FACTOR.md`**：谁能接手、密钥在哪、怎么发版 | 1 小时 | 陌生人可按文档发一次补丁 |
| **异地备份**：把核心 6 仓 + 全部报告打包到第二处（另一账号/另一盘/离线） | 2 小时 | 断网/封号可恢复 |

| **发布应急 runbook**：yank、撤回 release、通知 | 1 小时 | 出事有人照做 |
