## 1. 新增事实（第二家真实实现：agentpin 0.3.0）

| 项 | 事实 | 证据 |
|---|---|---|
| 撤销文档结构 | `agentpin_version` / `entity` / `updated_at` / `revoked_credentials` / `revoked_agents` / `revoked_keys` | `agentpin/revocation.py:6-38` |
| **撤销文档无签名** | 全文无 `sig` / `sign` / `serial` 字段；通过 `.well-known/agent-identity-revocations.json` 走 HTTPS 取 | `revocation.py` 全文检索 0 命中；`discovery.py:28` |
| 钉扎 | TOFU 按 **domain**；换钥 → `KEY_PIN_MISMATCH` **硬失败** | `pinning.py:14-38`、`verification.py:173` |
| **只支持 EC P-256** | `crypto.py:22 ec.generate_private_key(SECP256R1())`；JWK 只有 EC | `crypto.py:10,22`；`jwk.py:39,50` |
| **Ed25519 的 JWK 直接崩** | `jwk_thumbprint` 用 f-string 拼 `crv/kty/x/y`，OKP 无 `y` → `KeyError:'y'` | `jwk.py:71-77`，实测 P30 |

**注意归因边界**：OpenClaw 上该技能的介绍页写的是"Ed25519 keypairs"，而 PyPI 0.3.0 的 `jwk.py` 只吃 EC P-256。**两者矛盾**——但介绍页可能描述的是另一个版本或另一套实现，所以这条标 **INFERENCE**，不标 FACT。

## 2. 两家对照：我们的差异还剩几条

| 维度 | aip-protocol 0.4.0 | agentpin 0.3.0 | 我们 |
|---|---|---|---|
| 一致性向量 | **31 条**，A–H 八类，实跑 31/31 | 有 `tests/` 但无跨语言向量 | 30 条，双语实现 diff 0 |
| 钉扎 | 无 | **TOFU + 硬失败** | 按 issuer + 指纹 + 撤销集 |
| 撤销文档签名的 | 无 | **无** | **Ed25519 签名** |
| 单调序号 | 无 | 无 | **serial 单调** |
| 历史不可篡改 | 无（`reinstate` 直接删记录） | 无 | **链式哈希** |
| 离线可验 | 否（内存 store） | 否（HTTPS 拉取） | **是** |
| 时效 fail-closed | 部分（`last_sync_time`） | 否（文档无 ttl） | **是** |
| 撤销粒度 | full/scope/delegation/principal | credential/agent/key | IDENTITY/EVIDENCE/AUTH/VERSION |

**结论**：两家都没有"签名 + 单调序号 + 链式历史 + 离线"这四件套。这不是我们更强，而是**我们选择了不同的取舍**。对外只能说"我们补这一层"，不能说"我们更安全"。

## 4. 给第三方的入口（本轮新增）

之前的问题：别人拿到一堆 `.py` 也不知怎么用。现在有 CLI：

```powershell
# agentpin 的撤销文档
python interop.py --format agentpin --file doc.json --entity agent-X

# AgIS 状态文档
python interop.py --format agis --file status.json

# AIP CRL
python interop.py --format aip --file crl.json --entity did:aip:abc --strict

# Clawdentity 签名 CRL
python interop.py --format clawdentity --token crl.jwt --pubkey <hex> --entity did:x
```

输出是 JSON（`verdict` / `reason` / `format` / 实体数 / strict / max_age），退出码 0=ALLOW、1=DENY，可直接进 CI。

实测两条：
- `agentpin 文档 + agent-X` → `DENY / revoked:full_revoke`（exit 1）
- `同文档 + agent-Y + --strict` → `DENY / no_history_proof`（exit 1）

**这才是"可被第三方使用"的最低门槛**：不是给代码，是给一个能跑出判定的命令。
