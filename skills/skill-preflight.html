What it is / 是什么

Zero-token pre-listing check for any SKILL.md against a weighted D1-D10 rubric: trigger design, metadata, structure, verifiability, boundaries, disclosure hygiene, size, provenance, internationalisation, resources. Use before listing or publishing a skill.

技能上架前的零 token 体检门禁。对任意 SKILL.md 按 D1-D10 十维加权 rubric（触发设计/元数据/可执行性/可验证性/边界诚实/去敏纪律/体量/署名/国际化/资源配套）算出 0-1 分与 A/B/C/D 档，给出在 688 个真实技能库中的百分位、逐维与全库均值的落差、泄密形态扫描结果，以及只列 3 条的补强动作；另附『SkillHub 评测对齐度』诊断（七段式骨架覆盖 + 缺哪段），并支持外部 G1 敏感词表（商号等，不硬编码、不随包发布）。全程读磁盘、不调 LLM、不联网，分数可复算、可 diff、可进 CI。触发词：技能体检、skill 体检、技能评分、skill 打分、技能质量、上架前检查、skill preflight、发布门禁、技能审计、SKILL.md 检查、骨架诊断。

When to use it / 什么时候用它

  • 技能要发布到任何市场（ClawHub / SkillHub / SkillPie / HF / BuiltinMarket）之前
  • 上线前需要客观判据判断这件技能够不够格
  • 想知道一件技能在真实技能库里排第几、差在哪几维
  • 要把技能质量做成 CI 门禁
  • 收到外部技能，想先体检再决定装不装
