# XLGD 开放生态治理战略 —— 落地方案

**日期**：2026-11-19 · **性质**：研究与规划（本战略批准范围内）
**未做**：协议正式发布、品牌授权、认证计划、商业合作、对外承诺、代码合并、仓库修改
**标注**：FACT / INFERENCE / NOT VERIFIED / BLOCKED

## 0. 先说最硬的一个数

战略第一句是"从创始人主导发展为第三方生态"。那么必须先知道现在离"第三方"有多远。

**四个核心仓 129 个 PR 的全量统计（FACT）**：

| 口径 | 数量 |
|---|---|
| PR 总数（全状态） | 129 |
| 外部作者 PR | 19 |
| 外部作者**唯一数** | **2** |
| 其中机器人 | `dependabot[bot]`（18 个） |
| 其中真实人类 | **`Enard52`（1 个，已关闭未合并）** |

也就是说：**真实人类外部贡献者 = 1，且那一个被静默关闭了。**

这不是要打击谁，而是战略的起点坐标。任何"开放生态"叙事如果不先说这个数，就是自我安慰。

## 4. 治理机制设计（文档级，未生效）

### 4.1 规则提案流程（RLP）

```
DRAFT → DISCUSS(≥14 天) → ACCEPTED → IMPLEMENTED → VERIFIED → ACTIVE
                    ↘ REJECTED（记录理由，不删除）
```

提案必填字段：`rlp_id / 动机 / 影响的 rule_id / 兼容性影响 / 正反向测试 / 弃用计划 / 提案人 / 利益冲突`。
**争议处理**：任一方可在 DISCUSS 期提交反例；**有反例未解决不得进入 ACCEPTED**（这条直接来自 S4/V4、S5/V5 的真实分歧）。

### 4.2 贡献者等级与权限

| 等级 | 获得条件 | 可做 | 不可做 |
|---|---|---|---|
| C0 观察者 | 注册 | 提 issue、参与讨论 | — |
| C1 贡献者 | ≥1 PR 被合并 | 提 PR、被指派 issue | 合并他人 PR |
| C2 评审者 | ≥3 次实质 review 且被采纳 | 评审、批准 C1 的 PR | 发版、改规则 |
| C3 维护者 | 2 名现有维护者提名 + 6 个月记录 | 合并、发版（需 1 人复核） | **改 LICENSE / 品牌 / 对外声明** |

**永恒保留**（不可委托）：许可证变更、品牌授权、认证声明、对外承诺、重大版本发布。

### 4.3 版本与兼容政策

- `SPEC_VERSION` 与包版本**分离**（当前 `0.4.0` 包 + `0.3.3-proposal` 规范就是没分离的后果）
- major 变更 = 破坏性，必须提供迁移路径
- 弃用期 ≥ **2 个 minor 版本**，不得静默删除
- 兼容矩阵随版本发布，未知组合一律 UNKNOWN（fail-closed）

### 4.4 品牌与认证使用规则

| 用法 | 允许 | 条件 |
|---|---|---|
| "compatible with UIBC 0.4" | ✅ 描述性 | 需通过兼容性测试并注明版本 |
| 产品名含 "XLGD"/"UIBC" | ❌ | 需书面授权 |
| "XLGD Certified" | ❌ | 认证计划尚不存在，任何人不得使用 |
| 引用理论与论文 | ✅ | 保留出处与作者 |

**当前状态**：`ecosystem.json` 自述 `entity_or_trademark_registered: false` —— **商标未注册，品牌授权没有法律基础**。这是必须先解决的前置项（INFERENCE：需法务确认）。

### 4.5 授权矩阵（回应第 7 条原则）

| 事项 | 谁可决定 |
|---|---|
| 文档修正、typo、测试补充 | 任一 C3 维护者 |
| 规则新增（非破坏性） | C3 + RLP 通过 |
| 合并业务代码 | C3（需第二人复核） |
| 发版、改 SPEC 版本 | **Steven Zhao** |
| 许可证 / 品牌 / 认证 / 对外声明 / 商业合作 | **Steven Zhao** |

| 层 | 内容 | 许可 | 收费 |

## 8. 结论

开放生态的瓶颈**不在协议设计**——协议、向量、运行器这套已经能用了。

瓶颈在两处：
1. **没人知道它存在**（外部贡献 1 人且被关）
2. **没有可授权的品牌与商业边界**（商标未注册，协议/商业边界未书面化）

所以第一阶段的重点不该是"再写规范"，而是把已有的东西**变成外部人能 30 分钟接上的入口**，并把商标与边界这两件法律性前置项处理掉。
