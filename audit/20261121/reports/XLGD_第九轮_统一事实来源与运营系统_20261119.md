## 0. 本轮最重要的一个发现

**既有的 SSOT 雏形已经存在，但它是个"叙事索引"，不是"事实账本"。**

`zhaoxinghua09-cell/xlgd` 仓（43 KB）自带 `ecosystem.json`，首行自述：
> `"Machine-readable umbrella index for XLGD. Single source for the ecosystem map; prose lives in README.md."`

实际情况（FACT）：
- 它只列了 **6 个 layer**：`lgd-theory / uibc-core / silent-failure-catalog / uibc-competition / agent-skills / lgd-hub`
- 本轮认定的核心资产有 **13 个**——LGD-Eval、skill-audit、lgd-gate、skillgate、synomosai-governance-mcp、medxpert-reg-connector **全都不在里面**
- 它没有任何字段承载 **SHA / 版本 / 状态 / 最近验证时间 / 负责人**
- 它声明 umbrella `license: MIT`，而 uibc-core 是 Apache-2.0 → 许可边界自相矛盾

**结论**：不要新建 SSOT，把 `ecosystem.json` 降级为"人读叙事索引"，另建机器账本。下面的 Asset Registry 就是这个账本的第一版。

## 5. 交付物六：证据生命周期规范

**核心原则：不同对象有效期不同，禁止统一 TTL。**

| 对象 | 生成 | 生效条件 | 有效期 | 过期行为 | 依据 |
|---|---|---|---|---|---|
| 测试运行记录 | CI / 本地 | 绑定 commit SHA + 命令 + 环境 | **跟 commit 走**，SHA 变即失效 | 标 STALE | 代码变则结论不成立 |
| 评测报告 | LGD-Eval run | 报告含规则版本 + 引擎版本 + 语料版本 | **90 天** 或规则版本变更即失效 | 需复评 | 攻击手法演进快 |
| 证据锚（OTS/Rekor/RFC3161） | 打包时 | 锚验证通过 | **永久**（不可再生，不设过期） | 不适用 | 时间证明是一次性的 |
| 授权记录 | 授权签发 | 评测有效 + 主体身份有效 + 策略有效 | **30 天** 或任一前置失效即失效 | 自动 NOT_GRANTED | 三方分离后授权最脆弱 |
| 法规来源（MedXpert） | 采集 | 原文哈希 + 解析器版本 | **30 / 90 天**（按法规层级分档） | overdue 告警 + fail-closed | 法规更新不可预知 |
| 身份/公钥 | 注册 | 钉扎 + 撤销检查 | **365 天** 或轮换/撤销即失效 | 强制重注册 | 密钥周期惯例 |
| 资产台账（本轮） | 脚本抓取 | — | **7 天** | 重跑脚本 | 仓库状态每天都在变 |

**状态机**：`GENERATED → VERIFIED → EFFECTIVE → (EXPIRED | REVOKED) → RE-REVIEWED`
**禁止**：`EXPIRED → EFFECTIVE`（必须经 RE-REVIEWED）；`REVOKED → EFFECTIVE`（不可逆）。
