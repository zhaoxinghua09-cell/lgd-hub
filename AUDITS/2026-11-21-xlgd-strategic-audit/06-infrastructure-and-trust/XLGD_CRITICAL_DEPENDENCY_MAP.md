# XLGD_CRITICAL_DEPENDENCY_MAP（关键依赖与控制点地图 · 2026-11-21）

> 目的：找出"它一挂，整个生态就停"的单点。**结论：共 3 个 P0 单点——GitHub 账号、Rekor 在线签发、Python 生态依赖。**

## 一、依赖地图（10 类）

| 依赖 | 关键度 | 失败影响 | 替代方案 | 迁移成本 | 数据可迁移 | 恢复方式 | 判定 |
|---|---|---|---|---|---|---|---|
| **GitHub（账号/仓库）** | **P0** | 全部代码/issue/release/Actions 停摆 | GitLab/自建 Gitea/本地镜像 | 中（改 CI） | 是（git 全历史） | 本地克隆 + 镜像组织 | **最大单点** |
| **PyPI** | P0 | 无法分发 | 私有索引/直接 wheel | 低 | 是 | 换源 | 单点但可控 |
| **Rekor（sigstore 公共日志）** | **P0** | 无法签发新证据；已签的仍可离线校验 | 自建透明日志/OTS/RFC3161 | **高** | 部分（`--log-key` 可离线验） | 用第二锚（OTS） | **半可用** |
| **GitHub Pages（文档）** | P1 | 文档不可访问 | 任意静态托管 | 低 | 是 | 换托管 | 低 |
| **GitHub Actions** | P1 | CI 停 | 本地运行 + 其他 CI | 中 | 是 | 本地跑 1015 例 | 可替代 |
| **Python 3.13 / 依赖** | P1 | 工具不可跑 | venv 固定版本 | 低 | — | 锁版本 | 可替代 |

| **Docker（沙箱）** | P2 | `--sandbox` 不可用（Windows 已实测受限） | Linux unshare | 中 | — | 跳过沙箱 | 局部 |
| **账号/密钥（ucvault + DPAPI）** | **P0** | 无法发版/签名 | 硬件密钥/纸质恢复码 | 中 | — | 恢复码异地保存 | **无异地** |
| **维护者本人** | **P0** | 一切停 | 第二 maintainer + 交接文档 | 高 | 是 | `BUS_FACTOR.md`（未写） | **最大风险** |

## 二、三个 P0 单点的处置

| 单点 | 现状 | 处置（低成本→高成本） |
|---|---|---|
| GitHub 账号 | 4 账号同人、无镜像组织 | ①建 org 镜像（半小时）②异地 clone ③第二 maintainer |
| Rekor 在线签发 | 只有 1 种锚 | ①加 OTS/RFC3161 双锚（已有工具痕迹：`docs/ANCHOR-CHANNEL.md`）②记录"不可用时的降级" |
| `cryptography` 缺失 | **静默通过**（本机实测 exit 0） | 改为 `INCONCLUSIVE` + 非零（1 行判定） |
