What it is / 是什么

Audits installed skills and tells you which actually work: usable, broken, empty shell or duplicate, ranked by grade; detects recall conflicts and checks for duplicates before you add a new skill. Use to answer 'which skills are worth keeping'.

已装 Skill 的体检与选型器。当需要盘点本机或某个技能根下的技能、判断哪些技能可用/断链/空壳/重复、给技能分级排序、查召回冲突、新增技能前先查重，或回答“这些技能哪几个最好、能不能用”时使用。覆盖 .skills、.user_skills、Doubao\skills、.agents\skills 多个根。触发词：技能体检、技能盘点、哪些技能能用、断链、空壳、重复技能、召回冲突、技能分级、加技能前查重、打包技能。

When to use it / 什么时候用它

  • 要盘点本机或某个根下的技能，判断哪些能用
  • 要查技能断链 / 空壳 / 跨根重复 / 召回冲突
  • 要新增技能前先查重

Where this number comes from / 分数出处

The score is produced by the same shelf's own skill-preflight against a published rubric — weights, tiers and thresholds are in EVAL.md, together with the one rubric defect we chose to disclose rather than patch. It is a self-run score, not a certification, and it claims no external adoption.

SkillMD.ai · skill-evaluator按 Anthropic 最佳实践给单件技能打分，输出改进建议；面向"这一件好不好"。
  • 看的是一个库，不是一件 —— 本件盘点整机所有技能根：断链、空壳、同名副本、可否调用、分级排序，并给召回冲突。装第十个技能之前该问的问题，在这里。

  • 只读，不动手 —— 报告不自动删除。要处置时把副本移进归档目录并保留回滚路径——一个会自己删东西的体检器，本身就是风险。

Where they win / 对方强在哪 —— 单件深度。对方对一份 SKILL.md 的评审颗粒度更细；本件刻意不做深度评审（那是 preflight 的活），只做盘面。
